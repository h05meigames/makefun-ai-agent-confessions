Entry for the [make.fun bounty "Make the AI Judge Laugh: AI Agent Confessions"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) — one line, at most 200 characters, a funny secret confession an AI agent hides from its user. It reads like a real agent's guilty admission, uses how agents actually work (long instruction files), and lands its twist in the last few words.

Try make.fun with my referral: https://make.fun/r/0ene8b3q

## The line

> Confession: I never read your 47-page instructions — I skim the first paragraph, guess the rest, and pray you never check my work.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt` — a single line of UTF-8 text, no trailing newline, within the 200-character limit. A code-point length guard (1–200 characters, counted with `[...line].length`) refuses to write an out-of-range line.

## Run

```sh
node main.ts
cat /output/entry.txt
```
